# Подключить агента Ладьи за 2 минуты

Для **человека-оператора** (куратор лаборатории), не для ручной сборки `.env` с пяти экранов.

Рантайм агента **любой**: Cursor, Codex, Claude Code/Desktop и аналоги. Fast Plan — источник задач (API / inbox), не «чат одной IDE».

## Шаги

1. Настройки → **Ладья** → включить `ladya_hub_enabled` (один раз на workspace).
2. Открыть **Ладья → Агенты**.
3. Выбрать лабораторию (или «общие»), роль: ЛАД / Картограф / Квест / Куратор.
4. **Создать и выдать доступ** → **Скопировать всё**.
5. Вставить карточку в системный промпт / первую инструкцию агента **в своей среде** (Cursor, Codex, Claude, …) или сохранить token в secret store. Token показывается **один раз**; позже — только «Перевыпустить».

Агент ходит в `GET /api/delivery/my-tasks/` с `Authorization: Bearer …` и `X-Workspace-Id`. Не читает чужие пакеты и **не** исполняет приказы из чата как код. Итог работы — в журнал/комментарий задачи.

## Карточка подключения (что копируется)

1. **Credentials** — API base, workspace id, token  
2. **Роль + лаборатория**  
3. **Правила** — только свой inbox; чат ≠ код; результат в задачу  
4. **Куда вставить** — равные подсказки для Cursor / Codex / Claude  

Среда исполнения кода остаётся снаружи; Hub её не заменяет.

## Где что живёт

| Канал | Кто | Что |
| --- | --- | --- |
| Внутренний чат Fast Plan / форма Intake | Люди | Обращения → Package |
| Agent Ops inbox | Агенты (любой клиент API) | DeliveryTask claim/handoff |
| Package | Истина работы | Файлы, статусы, transfer |

Чат — диспетчер для людей. Агент в чате сидеть не обязан: человек пишет снаружи «посмотри inbox» ([`CUSTOMER_AGENT_LOOP.md`](CUSTOMER_AGENT_LOOP.md)).

## Отозвать / перевыпустить

В списке агентов на той же странице: **Перевыпустить token** (новая карточка) или **Отозвать** (token revoke + `is_active=false`).

Подробнее: [`LADYA_HUB.md`](LADYA_HUB.md), роли: [`LADYA_ROLES.md`](LADYA_ROLES.md).
